# Matchmaker

Most programmers start by saying "Hello World!" – I started by asking the world who loves whom.

My very first code: a love calculator inspired by a game we played on paper at school.
Type in two names, it counts the letters of I LOVE YOU in them and adds the
neighbouring digits row by row until a love percentage is left.
The "how many missing to 100%" button tells you which letters to add to reach 100%.

**Live:** https://mazsola739.github.io/rika-hello-world/

## Built with

HTML, CSS and JavaScript – no libraries, no build step.

- `index.html` – the page with the three boxes and the table
- `script.js` – the calculation and the 100% button
- `style.css` – the sky blue styling

## History

Open `index.html` in a browser. The `main` branch is published with GitHub Pages.
